Questions

  
Can I get banned for using Luger?
Luger only sends keyboard and mouse input, the same as you pressing keys. It never reads or changes the Roblox client. Use it in games whose rules allow macros, and check a game’s rules if you are unsure.

  
How do I get a key?
Join the Discord for a free key, or buy a weekly, monthly or lifetime key inside the app. Paid keys activate as soon as checkout finishes.

  
Will my AutoHotkey scripts work?
Common scripts convert completely: hotkeys, sends, clicks, loops, pixel searches, timers and simple windows. Anything Luger can’t convert is kept as a marked comment and listed, so nothing disappears quietly.

  
Are shared macros safe?
Every macro is scanned for malware and hidden code before it can run or be published, and macros run in a sandbox with no internet or file access outside their own folder.

  
Which computers does it run on?
Windows 10 and 11, macOS 12 or newer (Apple silicon and Intel), and Linux (AppImage or .deb). On a Mac, allow Luger under Accessibility the first time a macro runs.
