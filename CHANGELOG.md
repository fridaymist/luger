# Changelog

Luger's version is shown only in Settings → About. Every release bumps it here and in
package.json; the app updates itself. 1.0.0 is reserved for the first fully public release.

## 0.9.1
- Get key opens the Luger Discord.
- Every screen scrolls properly in smaller windows.
- Text can no longer be highlighted by accident (fields and keys still can).
- Installers for Linux and both kinds of Mac.

## 0.9.0 — first complete build
- Key system: free keys through ad checkpoints, weekly/monthly/lifetime keys through Stripe, owner key panel.
- Bootstrapper: live Roblox game data, playtime from Roblox logs, launching, tweaks, Discord status.
- Apps: Auto Clicker and Recorder.
- Macros: library, AutoHotkey → Python conversion, malware scan and clean, key-bind editing, in-app macro windows.
- Explore: publishing, reviews, verified creators, reports and moderation.
- Profile: themes, frames, effects, titles, achievements and per-game mastery.
- Marketplace: daily shop, ammo and crystals, local currency prices.
